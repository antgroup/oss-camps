# 2026 蚂蚁开源轻训营·高校行活动指南

## 活动介绍
蚂蚁开源轻训营 · 高校行活动围绕“开源任务挑战”展开。项目组准备适合学生参与的轻量级 Issue，学生在认领任务后进入线上实战周期，由项目 Owner 和导师进行答疑、Review 和验收。最终以有效贡献为准，评选优秀学生并沉淀贡献案例。

高校行整体遵循“线上参与活动 + 每月一场校园 Workshop”的节奏推进。

🙋‍ 线上：面向所有高校学生，全程线上进行，包括认领任务、导师答疑、实战提交

👨‍🏫 线下：每月一场校园 Workshop，蚂蚁开源项目 Owner 与高校同学现场互动交流，分享开源社区文化、技术发展趋势与项目实操经验

## 面向受众
● 对开源感兴趣，但不知道从哪里开始的高校同学

● 学过 Git 和编程基础，希望参与真实项目实践的同学

● 已经提交过 PR，希望进一步理解社区协作方式的高校开发者

● 对代码、文档、测试、设计和社区运营感兴趣的高校开源参与者

你不需要已经是“开源高手”。认真阅读任务要求、主动沟通并遵守社区协作规范，就是最重要的开始。

## 活动规则
加入【蚂蚁开源轻训营】云燕实验室 https://antgroup.beta.oscollege.net/os/compete/98 （需注册云燕学习平台），即可查看、认领【2026 蚂蚁开源轻训营 · 高校行】专属 Issue 并提交 PR，专属 Issue 仅供通过云燕平台参与活动的同学认领。

【认领时间】即日起至 12/31 截止提交 PR

【活动报名】加入【蚂蚁开源轻训营】实验室，信息收集仅用于活动登记和奖励发放。

【认领方式】在云燕平台任务板块点击“认领”按钮即成功认领对应 Issue。

【提交成果】在云燕平台已认领 Issue 处点击“提交 PR”按钮上传 PR 链接。

【激励发放】活动结束后公示评选结果，奖品将在结果公示后陆续发出。
